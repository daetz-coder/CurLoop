快速上手

1. 初始化项目：在「控制台」点「初始化项目」，输入最终目标 → 生成 FinalGoal.md / TODO.md；或用命令行 curloop init --final-goal。

2. 设置参数：所有运行参数都在「控制台 → 运行参数」面板统一调整（模式 / 任务上限 / 换号上限 / 线程轮转 / 进度检查点 / 最终验收），点「保存参数」后下次运行生效。

3. 开始运行：在「控制台」填入目标项目（默认当前项目）→ 点「开始运行」。运行日志实时显示在下方终端，刷新页面不中断。

4. 查看结果：「总览」看统计与近 24h 活动；「轨迹」看任务时间线（支持缩放拖拽）；「队列 / 事件 / 报告」看明细。

使用须知

· 运行模式：默认跟随配置文件（dry-run，只读预览）；全链路测试请设为 live（需要管理员——用管理员终端运行 curloop web）。

· 自动换号：撞到用量/登录限制时自动切换账号（需在配置中指定换号助手 CursorLoginAssistant-*.exe 与模板图片）。

· 停止：写入 <项目>/STOP 文件 → loop 优雅收尾（退出码 2，watchdog 不重启）；删除文件可取消。Web 里点「■ 停止」即自动创建。

· 长对话：线程轮转 每 N 个任务开新对话并用 HARNESS_STATE.md（自动生成的记忆）续接；进度检查点 让 Agent 定期写进度小结。

· 恢复：中断/崩溃后状态自动保存（snapshot + TODO 合并），再次运行即可续跑；report.json 记录每次结束摘要。

· 终端命令：curloop web（本界面）、curloop run、curloop status、curloop plan、curloop init；flag 模式 curloop --check-config / --dry-run。
